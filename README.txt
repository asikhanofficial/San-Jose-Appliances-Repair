HOW TO TEST LOCALLY (OFFLINE / DESKTOP)
----------------------------------------------------------------------
1. Simply double-click `index.html` in your file explorer.
2. The site opens immediately in Chrome, Safari, Firefox, or Edge.
3. All CSS styles, JavaScript interactions, and images load reliably
   via relative paths (`assets/...`).
4. Embedded JavaScript automatically translates clean links to local `.html`
   files when navigating via the `file://` protocol.

----------------------------------------------------------------------
HOW TO DEPLOY ON HOSTINGER / APACHE
----------------------------------------------------------------------
1. Connect via FTP or Hostinger File Manager to your domain directory (`public_html/`).
2. Upload all files and the `assets/` folder to the root of `public_html/`.
3. Ensure `.htaccess` is uploaded (enable "Show Hidden Files" in your FTP client).
4. The `.htaccess` file will automatically:
   - Route clean URLs (`/about`, `/services`, `/refrigerator-repair`, etc.)
   - Redirect any `.html` extensions to their canonical clean URLs
   - Enable browser caching for lightning-fast page loading
   - Provide security headers
